# 🏦 Bankist App

A responsive online banking web application built with vanilla JavaScript, featuring transfers, loans, and real-time financial summaries.

## 🚀 Features

- **User Authentication:** Log in using username initials (e.g., `js` for Jonas Schmedtmann) and PIN.
- **Movements Display:** View chronological transaction history with deposits and withdrawals labeled.
- **Dynamic Balance & Summary:** Automatically calculates total balance, total incoming deposits, total withdrawals, and accumulated interest.
- **Money Transfer:** Transfer funds seamlessly to other existing accounts with balance verification.
- **Request Loan:** Apply for loans with automatic verification checks.
- **Close Account:** Delete account credentials using account verification.

## 🛠️ Built With

- **HTML5:** Semantic structure and form elements
- **CSS3:** Modern card UI and layout styling
- **Vanilla JavaScript:** DOM manipulation, Array methods (`map`, `filter`, `reduce`, `find`, `findIndex`), and Date handling
